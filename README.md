## 2. Тема та анотація до програми

**Тема:** інтерактивний веб-конструктор електричних схем з фізичною симуляцією та довідковим розділом про електронні компоненти.

**Анотація.** Програма дозволяє зібрати електричне коло з 16 компонентів (батарея, лампа, вимикач, кнопка, резистор, реостат, амперметр, вольтметр, світлодіод, діод, двигун, зуммер, запобіжник, конденсатор, котушка індуктивності, провід) і одразу побачити результат: лампа світиться, двигун обертається, зуммер подає звук, прилади показують струм і напругу, запобіжник перегорає при перевантаженні, а котушка показує магнітне поле. Коло розраховується методом вузлових потенціалів (закони Ома та Кірхгофа) з урахуванням полярності діодів. Зареєстровані користувачі можуть зберігати схеми та відкривати їх з будь-якого пристрою. Окрема сторінка «Інформація» розповідає про історію, принцип дії та цікаві факти про кожен компонент. Інтерфейс доступний українською та англійською мовами.

**Мова програмування та версія компілятора:** TypeScript 5.9.3 (компілятор `tsc`, режим `strict`, ціль ES2020, ES-модулі).

**Середовище виконання:**

- клієнтська частина працює в браузері без зовнішніх бібліотек і без зовнішніх ресурсів (шрифти, скрипти й зображення віддаються з самого сайту);
- серверна частина: Cloudflare Pages Functions (середовище Workers);
- база даних: Cloudflare D1 (SQLite);
- для збирання й розробки використовується Node.js (перевірено на версії 22.23.4).

## 7. Відомості про особливості установки та роботи програми

### 7.1. Локальний запуск (Windows PowerShell)

```powershell
git clone https://github.com/Boris-Yavorskiy/interactive_scheme.git
cd interactive_scheme
npm install
npm run db:local
npm run dev
```

Після цього відкрийте http://localhost:8788. Команда `npm run db:local` створює локальну базу даних і застосовує до неї міграцію `migrations/0001_init.sql`.

### 7.2. Розгортання на Cloudflare Pages

1. У панелі Cloudflare створіть базу D1 з назвою `interactive-scheme-db` (Storage & Databases → D1) і скопіюйте її ідентифікатор.
2. У файлі `wrangler.toml` замініть `YOUR_D1_DATABASE_ID` на цей ідентифікатор. Значення `name` має збігатися з назвою проекту Pages.
3. Застосуйте міграцію до бази Cloudflare: виконайте `npx wrangler login`, потім `npm run db:remote`.
4. У панелі Cloudflare відкрийте Workers & Pages → Create → Pages → Connect to Git, оберіть репозиторій і вкажіть:
   - Build command: `npm run build`
   - Build output directory: `public`
5. Після збирання сайт буде доступний за адресою `https://<назва-проекту>.pages.dev/`. Папка `functions/` підхоплюється автоматично як серверна частина.

Кожен `git push` у гілку `main` запускає нове збирання й публікацію автоматично.

### 7.3. Робота з програмою

Докладна інструкція для користувача є на сторінці «Довідка» (`/help`). Коротко:

- перетягніть компонент зі списку на полотно та з'єднайте термінали проводами;
- вимикач перемикається кліком, кнопка діє, доки її утримують;
- напругу батареї, опір резистора та реостата змінюють у панелі властивостей;
- амперметр вмикають послідовно, вольтметр паралельно;
- для збереження схем потрібна реєстрація (електронна пошта та пароль від 6 символів).

### 7.4. Структура проекту

| Шлях | Призначення |
|---|---|
| `src/lib/circuit-engine.ts` | розрахунок електричного кола |
| `src/lib/components-data.ts` | описи компонентів, виводи, розміри |
| `src/lib/geometry.ts` | положення виводів, форма проводів, пошук найближчого виводу |
| `src/lib/i18n.ts` | переклади інтерфейсу (укр/англ) |
| `src/lib/nav.ts`, `lang.ts` | навігація та перемикач мови |
| `src/lib/audio.ts`, `api.ts` | звук і запити до сервера |
| `src/builder/` | сторінка конструктора: стан, відмальовка, події миші, вікна входу та збережених схем |
| `src/info/` | сторінка «Інформація» і її тексти |
| `src/home/`, `src/help/` | головна сторінка та довідка |
| `functions/api/` | серверна частина (реєстрація, вхід, схеми) |
| `migrations/` | структура бази даних D1 |
| `public/` | HTML, CSS, зображення компонентів; сюди ж збирається JavaScript (`public/js`) |

### 7.5. Серверна частина (API)

| Метод і шлях | Дія |
|---|---|
| `POST /api/auth/register` | реєстрація та вхід |
| `POST /api/auth/login` | вхід |
| `POST /api/auth/logout` | вихід |
| `GET /api/auth/me` | поточний користувач |
| `GET /api/schemes` | список збережених схем |
| `POST /api/schemes` | зберегти нову схему |
| `GET /api/schemes/:id` | відкрити схему |
| `PUT /api/schemes/:id` | оновити схему |
| `DELETE /api/schemes/:id` | видалити схему |

Паролі зберігаються у вигляді хешів PBKDF2 (SHA-256, 100 000 ітерацій, випадкова сіль). Сесійний ключ передається в cookie `HttpOnly`, а в базі лежить лише його хеш. Користувач бачить і змінює тільки власні схеми.

### 7.6. Обмеження

- Керування розраховане на мишу, сенсорні екрани не підтримуються.
- Облікові записи зі старої версії на WordPress не переносяться, користувачам потрібно зареєструватися заново.
- Відновлення пароля не реалізоване.
- Кількість спроб входу не обмежується в коді. Для захисту від підбору пароля на Cloudflare можна ввімкнути правила Rate Limiting.
